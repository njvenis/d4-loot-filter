System architecture

AWS deployment
Custom code — we build Off-the-shelf — we configure External / SaaS

Everything runs in private subnets. The only egress is 443 through the NAT gateway to three allow-listed destinations, and the only inbound is Okta-authenticated users on the internal ALB. We poll GitHub rather than receiving webhooks, which removes the one inbound internet exposure the design would otherwise need — at the cost of up to 15 minutes' latency on issue-state changes, which is acceptable for this workload.
